# Predictive Analytics on Global Sustainable Energy Data

## Project Overview

This project explores global sustainable energy trends using Python and Machine Learning. It focuses on analyzing the relationship between economic growth, energy consumption, electricity generation, renewable energy adoption, and CO₂ emissions across different countries and years.

The project applies statistical analysis, data visualization, regression, classification, and association rule mining to identify meaningful patterns in the global energy dataset.

## Objectives

- Analyze global trends in electricity access and clean fuel usage.
- Explore renewable and non-renewable electricity generation.
- Examine relationships between GDP, energy consumption, and CO₂ emissions.
- Build regression models to study energy consumption and CO₂ emissions.
- Classify countries based on their low-carbon electricity share.
- Identify relationships between energy and economic indicators using association rules.

## Project Workflow

1. **Data Loading:** Imported and explored the Global Data on Sustainable Energy dataset.
2. **Data Preprocessing:** Handled missing values, examined outliers, and applied log transformations to highly skewed features.
3. **Exploratory Data Analysis:** Created histograms, boxplots, trend analysis, correlation heatmaps, and comparative visualizations.
4. **Regression Analysis:** Implemented Simple Linear Regression, Multiple Linear Regression, and Polynomial Regression.
5. **Classification:** Built and evaluated five machine learning classification models.
6. **Association Rule Mining:** Identified frequent patterns using Support, Confidence, and Lift.

## Machine Learning Algorithms

**Regression Models**

**Classification Models**
- Logistic Regression

## Model Evaluation

The classification models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC Curve and AUC Score
- Log Loss

**Key Observation:** KNN achieved the highest ROC-AUC score of approximately 0.96 in the reported evaluation, followed by SVM at approximately 0.91.
